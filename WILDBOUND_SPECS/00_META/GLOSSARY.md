# Glossary

| Terme | Définition normative |
|---|---|
| `Account` | identité de connexion, distincte du héros incarné |
| `Hero` | animal jouable appartenant à une classe permanente |
| `Class` | identité de gameplay initiale d’un héros |
| `Evolution` | branche spécialisée choisie au niveau 10 |
| `Advanced Form` | amélioration visuelle et mécanique de niveau 30, post-MVP |
| `Wildbound` | nom diégétique des héros joueurs |
| `Heartroot` | réseau vivant reliant les souvenirs d’`Alderwild` |
| `Fissure` | corruption locale du `Heartroot`, source d’événements |
| `Social Zone` | zone partagée en temps réel sans combat tactique direct |
| `Adventure Zone` | zone d’exploration partagée menant à des combats instanciés |
| `Battle Instance` | combat autoritaire privé sur grille |
| `Den` | tanière privée décorée et visitable |
| `AP` | Action Points consommés par les compétences |
| `MP` | Movement Points consommés par les déplacements |
| `Spirit` | jauge d’ultime limitée au combat courant |
| `Downed` | unité PvE neutralisée mais relevable |
| `Morphstone` | objet rare permettant de changer de branche d’évolution |
| `Mentor Scale` | normalisation temporaire d’un joueur haut niveau dans une zone basse |
| `Content version` | version du catalogue de contenu |
| `Balance version` | version des valeurs chiffrées utilisées pour un combat |
| `Protocol version` | version des messages échangés entre client et serveur |
| `Server-authoritative` | seul le serveur valide et persiste l’état sensible |
| `Idempotent` | répéter la même requête ne produit pas un second effet |
| `MVP` | contenu minimum requis pour la première version publique testable |
