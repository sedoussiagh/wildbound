# MVP Quest Catalog

## Main sequence

`A Seed of Memory` → `Whispers in Moss` → `The Pack We Make` →
`The Wild Mirror` → `Roots Remember` → `The Empty Antlers`.

`A Den of Your Own` branches after `Whispers in Moss` and does not block combat
progression. These seven quests define the narrative spine; the production MVP
target of 25 quests is completed later with Adventure Board and class variants.

## Modular rule

Each quest is a separate module. Prerequisites point only backward. Removing a
side quest requires reconnecting its children to the nearest valid prerequisite.
